Titanic Classification

A simple machine learning project using the Titanic dataset to predict passenger survival.

Model
Decision Tree Classifier
Train-Test Split: 80:20

Features Used

* Pclass
* Sex
* Age
* SibSp
* Parch
* Fare

Evaluation

The model was evaluated using:

* Accuracy
* Precision
* Recall
* Confusion Matrix

Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib

 
Files
Titanic_Classification.ipynb` — Classification notebook
Titanic-Dataset.csv` — Dataset
